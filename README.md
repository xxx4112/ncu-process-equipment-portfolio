## 三、使用说明

### 每周实验流程

```bash
# 1. 进入对应周次目录
cd experiments/week03-流体力学基础实验

# 2. 按模板填写 README.md，并放入代码 / 数据 / 图片
# 3. 提交本周成果
git add .
git commit -m "week03: 完成流体力学基础实验报告"
git push origin main
```

### 提交信息规范

| 前缀 | 含义 | 示例 |
| :--- | :--- | :--- |
| `weekXX:` | 提交某周实验成果 | `week05: 完成导热系数测定数据处理` |
| `docs:` | 文档 / 说明更新 | `docs: 补充实验原理笔记` |
| `fix:` | 修正错误 | `fix: 修正 week08 应力计算单位` |
| `data:` | 数据文件更新 | `data: 上传 week06 换热器原始数据` |
